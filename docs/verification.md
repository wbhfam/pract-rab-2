# Проверка соответствия заданию

Проверены общие требования PDF (страницы 4–7), вариант 6 (23–25)
и конец документа. После вариантов общих требований нет: PDF заканчивается
вариантом 40 на странице 127.

## Выполнено в проекте

- Python 3.11+, стандартная библиотека; нет получения зависимостей
  посредством pip, packaging, requests и других сторонних библиотек.
- Пять параметров только из TOML, проверка каждого параметра.
- Метаданные Python-пакетов для точной заданной версии по HTTP URL.
- Рекурсивный DFS, транзитивные рёбра, сохранение циклических рёбер.
- Отдельный тестовый репозиторий с большими латинскими именами.
- Временный вывод настроек, прямых зависимостей и порядка загрузки
  доступен в соответствующих исторических этапах, не засоряет финальный CLI.
- DOT в stdout; ASCII включается только настройкой из TOML.
- Три примера и фактическое сравнение с pip. Пояснения к штатным
  возможностям pip и условиям локального сравнения — в comparison.md.
- README.md, .gitignore, src, tests, исполняемый run.sh.
- Пять содержательных Conventional/Scoped Commits и теги этапов.

## Тесты и ограничения кода

Команда:

```sh
python3 -B -m unittest discover -s tests -v
```

Результат в Python 3.13.15: **32 теста, OK**. Сквозные HTTP-проверки
работают на localhost, внешняя сеть тестам не требуется.
Проверка состава трёх графов против фактического pip inspect выполнена
отдельно; имена, версии и активные рёбра совпали для всех трёх примеров.
Для независимой проверки условий в эталонном отчёте использован парсер,
встроенный в pip; он не импортируется приложением или его unittest-тестами.

Локальная проверка AST и текстов исходных файлов:

| Показатель | Результат | Ограничение задания |
| --- | --- | --- |
| Максимальная строка Python | 80 символов | 80 |
| Максимальная функция, включая docstring | 25 строк | 40 |
| Максимальное число аргументов, включая self | 4 | 7 |
| Консервативная оценка сложности по AST | 9 | 10 |

Оценка AST учитывает ветвления, циклы, обработчики исключений, логические
операторы и comprehensions; это локальная проверка, не отчёт внешнего линтера.
Функции имеют docstring; числовые константы сравнения вынесены в имена.
Нет файлов больше 1000 строк. Нет отслеживаемых архивов, бинарных файлов,
pycache, результатов сборки или настроек редактора.

Фактические демонстрации исторических этапов: demonstrations.md.

## Что требует действий вне локального проекта

1. **Публикация в публичный git-репозиторий ещё не выполнена.**
   В среде не подключён git-сервис. Команды публикации есть в README.
   Нельзя удалять .git или заново инициализировать историю.
2. Очная защита каждого этапа на семинаре выполняется студентом.
3. Внешний интернет не включён. Запросы к публичному PyPI не проверялись;
   демонстрации выполнены через HTTP на локальных снимках метаданных.
   Наличие указанных локальных версий в публичном PyPI не подтверждается.
4. У pip нет штатного графического дерева зависимостей. Сравнены его
   фактический порядок установки и штатный JSON-вывод pip inspect,
   а не вымышленная команда визуализации.
